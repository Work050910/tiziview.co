## 为什么 Mac 用户必须认准 Clash Verge Rev？

对于广大使用苹果 MacBook 与 iMac 的用户而言，过去最常用的 ClashX 与 ClashX Pro 早已停滞更新，在面对现代 macOS Sonoma 及后续系统的严格安全机制时经常出现系统代理异常掉线。基于最新开源内核开发的 **Clash Verge Rev for macOS**，完美解决了权限死锁与内核崩溃问题，成为了苹果生态下的新一代标杆客户端。

无论您使用的是最新的 Apple Silicon（M1/M2/M3/M4 系列芯片）还是老款 Intel 处理器，按照以下流程均可实现极速配置：

### 步骤一：根据芯片架构下载专属 DMG 安装包
1. 打开 GitHub 官方 Release 页面，仔细甄别对应的安装包架构：
   - 如果您的电脑是 M1/M2/M3/M4 芯片，务必下载包名包含 **`aarch64` 或 `arm64`** 的 DMG 文件；
   - 如果是老款 Intel 酷睿芯片，请下载包含 `x64` 的安装包；
2. 双击打开下载好的 `.dmg` 镜像，将 Clash Verge 图标按住并拖拽进系统的 `Applications（应用程序）` 文件夹中。

### 步骤二：首次启动的安全权限绕过技巧
苹果 macOS 拥有极其严苛的 Gatekeeper 守门员机制。首次双击启动时，系统可能弹出提示：“无法打开，因为 Apple 无法检查其是否包含恶意软件”。
- **正确解决方法**：按住键盘上的 `Control` 键不放，再次用鼠标右键单击应用程序列表中的 Clash Verge 图标，在弹出的右键菜单中点击“打开”；此时系统会多出一个**「仍然打开」**的按钮，点击即可顺利启动并永久记录信任。

### 步骤三：导入机场订阅并激活系统代理
1. 在机场后台点击“一键导入 Clash”或直接复制订阅链接；
2. 在 Clash Verge 左侧点击「订阅 (Profiles)」，粘贴链接并点击「导入」；
3. 右键下载完成的配置卡片选择「使用」；在「代理」面板选择延迟较低的香港或日本节点；
4. 进入「设置」，打开「系统代理」开关，Mac 顶部菜单栏将出现彩色的飞鸟图标，即刻打通外网。

## 常见排障与新手自查 (FAQ)

**Q：首次在 Mac 上打开 Clash Verge Rev 提示“无法打开，因为无法验证开发者”怎么办？**  
A：打开 Mac「系统设置 -> 隐私与安全性」，往下滑动找到“安全性”区域，在提示处点击“仍要打开”，并在弹窗中点击打开并输入开机密码即可。

**Q：Mac 客户端开启“系统代理”后，为什么 Safari 可以翻墙但某些海外 App 无法联网？**  
A：部分桌面应用不遵循 macOS 的系统 HTTP 代理设置。需要在 Clash Verge Rev 设置中安装并开启“TUN 模式”，创建虚拟网卡接管所有未配置代理的软件流量。
